# Practical Delivery & Acceptance Checklist

## A complete practice loop

Clarify requirements → build a minimal solution → verify with tools → review manually → reflect. Define acceptance criteria before asking AI to break down the task.

- Context: inputs, outputs, existing interfaces, environment, and fixed constraints.
- Tools: file search, tests, logs, and diffs.
- Debugging: reproduce, narrow the scope, hypothesize, verify, and fix.
- Review: correctness, failure paths, dependencies, credential handling, and maintainability.
- Evidence: observed results, uncovered boundaries, and next steps.
