# 项目复盘与技术深挖

用真实证据解释个人贡献、关键决策、结果与失败后的改进。

## 复习方法

每次选一个问题，先脱稿讲解，再补笔记。记录依据、尚未验证的假设和下一次复习时间。

熟练度：待复习 → 能解释 → 能独立完成 → 能应对追问。
